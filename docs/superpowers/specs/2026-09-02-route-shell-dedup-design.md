# 问答区与测试台布局去重设计

## 目标

消除 `/qa` 与 `/lab` 当前由根布局和嵌套布局共同渲染造成的双导航、双页脚，同时保留现有路由和 v0 视觉设计。

## 根因

根布局无条件渲染 `SiteNav`、主内容容器和页脚；`/qa` 与 `/lab` 的嵌套布局又分别渲染自己的完整页面外壳，因此两个路由各出现两套外壳。

## 方案

新增一个轻量的路径感知根外壳：

- `/qa` 及其子路由直接使用 `app/qa/layout.tsx`。
- `/lab` 及其子路由直接使用 `app/(lab)/lab/layout.tsx`。
- `/`、`/documents`、`/chunks`、`/debug`、`/evaluation` 等现有路由继续由根外壳提供当前 v0 导航、内容容器和页脚。

路径判断只匹配完整路由段，避免把 `/quality` 或 `/laboratory` 误判为专用布局路由。

## 视觉约束

- `/qa` 复用现有 `SiteNav`、全局颜色变量和 v0 页面间距、标题及页脚样式。
- `/lab` 复用同一套颜色变量、字体、卡片和表单组件，但保留深色测试台导航以区分内部工具与正式问答区。
- 旧路由不改变 URL、导航或视觉表现。

## 测试与验收

- 单元测试覆盖 `/qa`、`/qa/...`、`/lab`、`/lab/...` 和相似但不应匹配的路径。
- 运行现有测试与生产构建。
- 浏览器验证 `/`、`/qa`、`/lab` 均只有一个导航栏和一个页脚；`/qa` 保持 v0 问答视觉，`/lab` 保持独立测试台导航。

## 非目标

- 不迁移或删除旧路由。
- 不修改 API、权限模型或业务数据。
- 不重新设计 v0 视觉系统。
